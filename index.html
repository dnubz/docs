3. Entity Tidak Memiliki Method

Aturan gambar/arsitektur: Operator, OrderItem, ActivityLog, dan entity Sea-ORM lain adalah data. Method tidak diletakkan di entity; method bisnis ada di Service / use case, sedangkan method database ada di Repository / data access adapter. Entity hanya berisi field, relasi, dan hasil mapping tabel.

6. Sequence Pemanggilan dispatch_operator()

DispatcherPage
  -> Tauri Controller: dispatch_operator(operator_id, order_item_id)

DispatcherController
  -> validasi operator_id & order_item_id
  -> ApiClient.dispatch_operator(operator_id, order_item_id)

ApiClient
  -> HTTP POST /dispatcher/dispatch-operator
  -> body: DispatchOperatorRequest

Axum Inbound Adapter
  -> Json(payload): DispatchOperatorRequest
  -> service.dispatch_operator(payload.operator_id, payload.order_item_id).await

Service (Use Case)
  -> repository.find_operator(operator_id).await
  -> repository.get_order_item(order_item_id).await
  -> validasi availability, role, dan status
  -> buat OperatorActiveModel / OrderItemActiveModel
  -> repository.dispatch_operator(operator_active, order_item_active).await

Repository (Outbound Adapter)
  -> database_connection.begin().await
  -> operator.update(&tx).await
  -> order_item.update(&tx).await
  -> tx.commit().await
  -> insert_activity_log(log).await // jika fitur logging diaktifkan

Database
  -> update operator / order_item / activity_log

Return
  -> RepositoryTrait -> ServiceTrait -> Axum -> ApiClient -> Tauri
  -> DispatcherPage menerima sukses atau HTTP status error
